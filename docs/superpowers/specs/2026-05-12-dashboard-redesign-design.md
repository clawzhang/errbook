# 错题本全站改版与首页设计规格

## 1. 背景与目标

本次改版目标不是做局部换肤，而是将当前系统升级为一套完整的学习型仪表盘产品：

- 新增一个与参考图风格一致的首页，作为登录后的默认落地页
- 将登录页、注册页、主站仪表盘页统一成同一套视觉语言
- 补齐参考图中的导航结构，为新增栏目提供正式入口与正式页面
- 在尽量复用当前真实数据和现有接口的前提下，完成高还原度的界面改造

本次采用“视觉高还原 + 数据结构适配”的方案：

- 视觉层面尽量贴近参考图的布局、配色、圆角、留白、卡片层级与信息密度
- 数据层面优先复用当前系统已有的错题、复习、知识点、测试、统计能力
- 对于当前没有完整模型支撑的栏目，先提供正式页面与合理的信息结构，不伪造完整后台能力

## 2. 设计原则

### 2.1 产品方向

- 首页成为主入口，而不是直接落到错题本列表页
- 左侧导航从“工具型后台”转为“学习型仪表盘”
- 全站强调“记录、分析、复习、提升”的学习闭环

### 2.2 视觉方向

- 浅色、高透气感、学习型仪表盘风格
- 大圆角、柔和阴影、低对比描边
- 蓝色作为品牌主轴，绿色、橙色、紫色作为辅助状态色
- 不采用深色科技风，不做传统灰白后台风

### 2.3 实现原则

- 尽量不破坏现有核心业务接口
- 尽量通过布局壳子、共享组件、聚合接口完成升级
- 页面必须像正式产品页，不允许“建设中”式占位
- 首页及新增栏目优先展示真实数据，不造假指标

## 3. 信息架构与导航

### 3.1 登录后默认路由

- `/` 改为登录后的默认首页
- 未登录仍通过认证逻辑进入登录页
- 登录成功后的默认跳转从原 `/errors` 改为 `/`

### 3.2 主站导航结构

左侧导航调整为以下栏目：

- 首页
- 错题本
- 按学科
- 按知识点
- 考试记录
- 复习计划
- 知识点管理
- 标签管理
- 统计分析
- 设置

其中：

- `错题本、复习、测试、统计、设置` 为现有主流程的延展或重命名承接
- 新增栏目即使功能深度有限，也必须拥有正式页面和正式视觉结构

### 3.3 页面优先级

第一优先级页面：

- 首页
- 错题本
- 复习
- 统计分析

第二优先级页面：

- 按学科
- 按知识点
- 考试记录
- 复习计划
- 知识点管理
- 标签管理

## 4. 首页设计

首页按参考图的仪表盘结构落地，主要分为以下区域。

### 4.1 顶部欢迎区

- 左侧展示问候语、日期、学习状态提示
- 右侧展示搜索框、通知入口、用户头像菜单
- 搜索框第一版以统一样式和交互入口为主
- 后续可逐步接入题目、知识点、试卷等全局搜索能力

### 4.2 四张核心指标卡

首页顶部展示四张核心指标卡，布局和风格尽量贴近参考图。

建议指标定义：

- 错题总数
- 已掌握数量
- 待复习数量
- 复习正确率

数据来源：

- `错题总数`：来自现有错误记录统计
- `已掌握数量`：来自 mastery 统计
- `待复习数量`：来自 review / nextReviewDate 相关统计
- `复习正确率`：来自 review quality 聚合结果

### 4.3 趋势图区域

- 主图展示“错题趋势”或“新增错题趋势”
- 默认支持近 7 天视图
- 后续可以扩展时间范围切换
- 数据不在前端分散拼装，统一通过首页聚合接口返回

### 4.4 辅助分析模块

右侧配套展示两类辅助分析：

- 知识点掌握情况
- 错题分布

其中：

- 知识点掌握情况：按掌握度或错题集中程度展示前若干知识点
- 错题分布：按学科或来源展示占比

### 4.5 最近错题

- 展示最近录入或最近更新的若干错题
- 保留“查看更多”跳转到错题本
- 列表样式与参考图一致，但数据使用当前真实字段

### 4.6 最近复习 / 今日任务

- 展示最近复习记录或待复习任务
- 若“最近复习”数据不足，则优先展示“今日待复习 + 最近完成”
- 保证首页右下区域始终有内容，不出现空白面板

### 4.7 首页数据策略

新增首页聚合接口，例如：

- `/api/dashboard`

由服务端一次性聚合：

- 首页摘要指标
- 错题趋势
- 知识点掌握摘要
- 学科分布
- 最近错题
- 最近复习/待复习

目标：

- 减少首页多接口串联请求
- 避免首屏抖动
- 降低前端拼装复杂度
- 为后续首页模块扩展留出统一入口

## 5. 全站视觉系统

### 5.1 全局样式

通过 `globals.css` 调整全局设计 token：

- 背景色体系
- 前景文字层级
- 卡片底色与边框
- 主品牌色与辅助状态色
- 圆角体系
- 阴影体系
- 输入框与表单控件样式

### 5.2 通用界面组件

全站需要统一以下视觉组件：

- 大面板卡片
- 数据统计卡
- 区块标题栏
- 图表容器
- 列表项卡片
- 空状态模块
- 筛选面板
- 表单面板
- 页面头部区域

建议补充共享组件或共享样式层，避免每个页面单独拼样式。

### 5.3 布局骨架

主站布局统一重做：

- 更宽松的模块间距
- 更明显的页面头部感
- 更完整的侧边栏品牌区
- 更一致的顶栏结构
- 移动端使用同一套视觉语言的抽屉导航

### 5.4 图表视觉

图表配色统一为首页同一套色板：

- 主折线/主柱图使用品牌蓝
- 掌握类使用绿色
- 待办/提醒类使用橙色
- 辅助分类使用紫色/浅蓝

避免统计页与首页图表像两个系统。

## 6. 认证页统一设计

登录页与注册页统一成主站品牌的前门，而不是另一套独立风格。

### 6.1 登录页

- 保留表单居中结构
- 增加品牌图标区、欢迎语、说明文案
- 背景使用浅色渐变与柔和层次
- 登录成功后跳转到新的首页 `/`

### 6.2 注册页

- 与登录页保持同一视觉骨架
- 字段区、错误提示、按钮区统一样式
- 交互文案与品牌气质对齐

## 7. 新增栏目页面策略

### 7.1 错题本

- 保留现有核心能力
- 重做页面头部、筛选区、卡片列表、分页、空状态
- 与首页风格完全统一

### 7.2 按学科

新增正式页面，按学科聚合错题信息：

- 学科维度统计卡
- 各学科掌握度
- 待复习数量
- 最近错题

支持跳转到带筛选条件的错题本。

### 7.3 按知识点

新增正式页面，基于 `KnowledgePoint + Error` 展示：

- 知识点列表
- 掌握进度
- 关联错题数量
- 薄弱排序

如果层级关系可用，优先采用父子知识点结构。

### 7.4 考试记录

当前没有独立考试记录模型，但存在 `TestSession`。

第一版对外命名为“考试记录”，内部映射 `TestSession`，展示：

- 场次标题
- 科目或配置摘要
- 总题数
- 正确数
- 完成状态
- 开始/完成时间

### 7.5 复习计划

当前没有独立计划表，因此第一版做“复习日程 / 待办视图”：

- 今日待复习
- 即将到期
- 已完成
- 按日期分组的复习安排

核心数据基于 `nextReviewDate` 与 `Review` 聚合。

### 7.6 知识点管理

展示已有知识点体系与统计：

- 知识点树
- 排序
- 关联错题数
- 掌握情况摘要

如果当前没有完整维护操作，则第一版以浏览管理台方式呈现，不承诺完整编辑器能力。

### 7.7 标签管理

当前不存在标签模型，因此第一版不能伪装成真实标签 CRUD。

第一版页面定位为：

- 正式的标签体系展示页
- 分类维度组织页

主要展示推荐标签维度：

- 学科
- 来源
- 掌握度
- 年级学期

后续若需要真实标签功能，再补充数据模型和接口。

## 8. 实现边界

### 8.1 本轮明确包含

- 新首页
- 全站统一视觉改造
- 侧边栏与顶栏升级
- 登录页与注册页统一风格
- 新增栏目正式页面
- 首页聚合接口
- 核心页面重排与统一样式

### 8.2 本轮明确不强行承诺

- 不新增真实标签模型与标签 CRUD
- 不扩展独立考试业务系统
- 不实现手工编排复习计划表
- 不实现完整知识点后台编辑器
- 不提供暗黑模式

## 9. 错误处理与空状态

- 首页所有模块必须支持空数据态
- 新增栏目即使无数据，也要有完整页面结构和合理引导文案
- 聚合接口失败时，页面布局不能塌陷
- 图表在无数据时应显示清晰说明，而不是空白
- 移动端下导航、图表、列表必须避免横向溢出

## 10. 技术实现建议

### 10.1 优先改造层次

建议按以下顺序实施：

1. 全局样式 token 与根布局
2. dashboard layout / sidebar / header
3. 首页聚合接口与首页页面
4. 错题本、复习、统计分析重做
5. 新增栏目页面补齐
6. 登录页、注册页统一

### 10.2 接口策略

- 现有业务接口尽量保持兼容
- 新增页面优先复用已有接口
- 仅在聚合展示不足时新增小型聚合接口

## 11. 验证与验收

### 11.1 最低验证要求

完成实现后至少执行：

- `npm run lint`
- `npm run build`

### 11.2 关键手动验证页面

- 登录页
- 注册页
- 首页
- 错题本
- 复习页
- 统计分析
- 新增栏目入口页

### 11.3 验收标准

- 登录后默认进入新的首页
- 侧边栏与顶部栏整体风格明显接近参考图
- 认证页与主站风格统一
- 全站主要页面视觉一致
- 新增栏目全部有正式入口和正式页面
- 首页为完整仪表盘，不是简单欢迎页
- 现有核心功能仍可访问：登录、错题浏览、复习、测试、统计、设置

## 12. 规格自检结果

### 12.1 占位项检查

- 无 `TODO`
- 无 `TBD`
- 无未定义的核心模块

### 12.2 一致性检查

- 首页默认入口、全站导航、认证跳转、页面策略彼此一致
- 数据映射与当前 Prisma 模型能力一致
- 对缺失模型的栏目已明确边界，不存在“页面承诺”和“数据能力”冲突

### 12.3 范围检查

- 范围聚焦于“全站改版 + 首页 + 栏目补齐”
- 未扩展为新的学习产品全量重构

### 12.4 歧义检查

- “考试记录”明确映射 `TestSession`
- “复习计划”明确为现有复习调度视图
- “标签管理”明确不是第一版真实标签 CRUD
